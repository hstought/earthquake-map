# Earthquake Map Application Requirements

## Project Overview
A sleek, modern web application that displays real-time earthquake data on an interactive dark-themed map with filtering capabilities and automatic data refresh.

---

## Technical Stack

### Core Technologies
- **TypeScript** - Type-safe JavaScript
- **Vite** - Build tool and dev server
- **Leaflet.js** - Interactive map library
- **Tailwind CSS** - Utility-first CSS framework

### Dependencies
```
Production:
- leaflet: ^1.9.x

Development:
- typescript: ^5.x
- vite: ^7.x
- tailwindcss: ^3.x
- postcss: ^8.x
- autoprefixer: ^10.x
- @types/leaflet: ^1.9.x
```

---

## Data Source

### USGS Earthquake API
- **Provider**: United States Geological Survey (USGS)
- **Base URL**: `https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/`
- **Format**: GeoJSON
- **Update Frequency**: Every minute (server-side)

### Available Feeds
| Magnitude | Past Hour | Past Day | Past 7 Days | Past 30 Days |
|-----------|-----------|----------|-------------|--------------|
| All | all_hour.geojson | all_day.geojson | all_week.geojson | all_month.geojson |
| M1.0+ | 1.0_hour.geojson | 1.0_day.geojson | 1.0_week.geojson | 1.0_month.geojson |
| M2.5+ | 2.5_hour.geojson | 2.5_day.geojson | 2.5_week.geojson | 2.5_month.geojson |
| M4.5+ | 4.5_hour.geojson | 4.5_day.geojson | 4.5_week.geojson | 4.5_month.geojson |
| Significant | significant_hour.geojson | significant_day.geojson | significant_week.geojson | significant_month.geojson |

## Features

### 1. Interactive Map
- [x] Full-screen dark-themed map (CartoDB Dark Matter tiles)
- [x] Global view centered at coordinates [20, 0], zoom level 2
- [x] Smooth pan and zoom interactions
- [x] World copy jump for seamless horizontal scrolling

### 2. Earthquake Markers
- [x] Circle markers for each earthquake
- [x] Size scaled by magnitude (4px to 25px radius)
- [x] Color coded by magnitude:
  - Green: < 2.0 (Minor)
  - Lime: 2.0 - 3.0
  - Yellow: 3.0 - 4.0
  - Orange: 4.0 - 5.0
  - Red: 5.0 - 6.0
  - Dark Red: 6.0 - 7.0
  - Very Dark Red: 7.0+ (Major)
- [x] Hover effects with brightness increase
- [x] Click to view detailed popup

### 3. Earthquake Popups
- [x] Magnitude badge with color indicator
- [x] Location description
- [x] Timestamp (formatted)
- [x] Depth in kilometers
- [x] Coordinates (lat/lng)
- [x] Tsunami warning indicator (if applicable)
- [x] Link to USGS event page

### 4. Filter Controls
- [x] Magnitude filter dropdown:
  - All Earthquakes
  - M1.0+ Minor
  - M2.5+ Light (default)
  - M4.5+ Moderate
  - Significant Only
- [x] Time period filter dropdown:
  - Past Hour
  - Past Day (default)
  - Past 7 Days
  - Past 30 Days
- [x] Instant data reload on filter change

### 5. Statistics Display
- [x] Earthquake count badge
- [x] Last updated timestamp (relative time)
- [x] Animated refresh indicator

### 6. Auto-Refresh
- [x] Automatic data refresh every 30 minutes
- [x] Visual indicator during refresh
- [x] Timer reset on manual filter change

### 7. UI Design
- [x] Glassmorphism filter panel (backdrop blur, semi-transparent)
- [x] Dark theme throughout
- [x] Gradient logo icon
- [x] Magnitude scale legend
- [x] Loading overlay with spinner
- [x] Error toast notifications
- [x] Responsive design for mobile

---

## Default Settings
- **Magnitude Filter**: M2.5+ Light
- **Time Period**: Past Day
- **Map Center**: [20, 0] (centered on Atlantic)
- **Zoom Level**: 2 (global view)
- **Auto-Refresh**: 30 minutes
